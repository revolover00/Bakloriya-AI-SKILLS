# أنماط الأسئلة ومصائد الامتحانات: English Language — Grade 2 Baccalaureate — Term 2

## 1. Past Modals of Deduction

• `must have + P.P.` (استنتاج شبه مؤكد في الماضي).
• `can't/couldn't have + P.P.` (استحالة في الماضي).
• `might/may/could have + P.P.` (احتمال غير مؤكد).
• `should/ought to have + P.P.` (لوم أو ندم على شيء لم يُفعل).

## 2. Causative Form (Active vs Passive)

• Active: `have + person + inf.` / `get + person + to + inf.`
• Passive: `have / get + object (thing) + P.P.`

## 3. Wishes & Regrets

• Wish in Present: `wish / if only + Past Simple`.
• Regret in Past: `wish / if only + Past Perfect (had + P.P.)`.
• Wish in Future: `wish / if only + could / would + inf.`
