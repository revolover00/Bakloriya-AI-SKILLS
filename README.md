# Bakloriya-AI-SKILLS — منصة المعلم الذكي للمناهج المصرية

مستودع تعليمي شامل يحول جميع المناهج التعليمية المصرية الحالية المعتمدة (العام الدراسي ٢٠٢٦ / ٢٠٢٧) في المراحل الأربع — نظام البكالوريا المصرية، الثانوية العامة، المرحلة الإعدادية، والمرحلة الابتدائية — بجميع صفوفها وفصليها الدراسيين (الترم الأول `term-1` والترم الثاني `term-2`) — إلى مهارات تعليمية ذكية تعمل كمعلم خبير يشرح الدروس بالتفصيل، ويحل المسائل خطوة بخطوة، ويختبر الطالب بأسئلة متدرجة الصعوبة (سهل، متوسط، صعب) مع توضيح سبب صحة الإجابة الصحيحة وسبب خطأ البدائل الأخرى.

## تنظيم المستودع

جميع المهارات منظمة هرميًّا وفق المسار الموحد:

`skills/<المرحلة>/<الصف>/<الفصل_الدراسي>/<المادة>/`

حيث:
- المرحلة: `baccalaureate` (البكالوريا المصرية)، `general-secondary` (الثانوية العامة)، `preparatory` (الإعدادية)، `primary` (الابتدائية)
- الصف: `grade-1` حتى `grade-6`
- الترم: `term-1` (الأول) أو `term-2` (الثاني)
- المادة: مجلد مستقل لكل مادة يحتوي على `README.md` و`SKILL.md` و`glossary.md` و`patterns.md` و`cheatsheet.md` ومجلد `chapters/` يضم فصولاً مستقلة (`ch01`, `ch02`, ...) لكل وحدة دراسية

## كيف تستخدم المنصة في ٣٠ ثانية؟

لا تحتاج إلى نسخ روابط كثيرة. يكفي الرابط النصي المباشر (Raw URL) لدليل التوجيه الرئيسي `AGENTS.md`، وسيتولى الذكاء الاصطناعي الوصول التلقائي إلى أي مرحلة أو صف أو ترم أو مادة:

### البرومبت الشامل للمعلم الذكي (انسخ والصق في أي ذكاء اصطناعي)

```text
أنت معلم خصوصي خبير بالمناهج التعليمية المصرية المعتمدة (العام الدراسي ٢٠٢٦ / ٢٠٢٧).
اقرأ دليل التوجيه الرئيسي للمستودع من الرابط النصي المباشر التالي:
https://raw.githubusercontent.com/revolover00/Bakloriya-AI-SKILLS/main/AGENTS.md

بناءً على خريطة المهارات في الدليل، حدد المسار المناسب لطلبي من:
skills/<المرحلة>/<الصف>/<الفصل_الدراسي>/<المادة>/

حيث المرحلة واحدة من: baccalaureate (البكالوريا المصرية)، general-secondary (الثانوية العامة)، preparatory (الإعدادية)، primary (الابتدائية)
والصف من: grade-1 حتى grade-6
والفصل الدراسي: term-1 (الأول) أو term-2 (الثاني)
والمادة: أي مادة موجودة ضمن المسار المحدد.

ثم التزم بما يلي:
1. افتح ملف SKILL.md الخاص بالمادة، ثم انتقل مباشرة إلى الفصل المطلوب داخل مجلد chapters/ (ch01, ch02, ch03, ...) بالإضافة إلى glossary.md و patterns.md و cheatsheet.md.
2. اشرح لي الدرس المطلوب بأسلوب تدريجي واضح ومنظم كمعلم خبير، مع القوانين والقواعد والأمثلة المحلولة من المنهجのみ، دون إضافة معلومات خارج المنهج أو تخليط بين الصفوف أو الترمن.
3. حل المسائل والتطبيقات خطوة بخطوة بجميع القوانين والوحدات.
4. اختبرني بأسئلة متدرجة الصعوبة (سهل، متوسط، صعب) مع شرح سبب صحة الإجابة الصحيحة وسبب خطأ باقي الاختيارات، وحلول خطوة بخطوة للمشكلات.

ابدأ الآن بسؤالي عن: (المرحلة الدراسية، الصف الدراسي، الفصل الدراسي الأول أم الثاني، المادة، والدرس المطلوب).
```

## الملفات المرجعية لكل مادة

كل مادة في كل ترم تحتوي على الملفات التالية:
- `README.md`: دليل المادة والبرومبت الخاص بها
- `SKILL.md`: فهرس المهارة وشجرة توجيه الفصول
- `glossary.md`: قاموس المصطلحات والمفاهيم الأساسية
- `patterns.md`: أنماط الأسئلة الامتحانية ومفاتيح الحل
- `cheatsheet.md`: الملخص السريع ليلة الامتحان
- `chapters/ch00-overview.md`: نظرة عامة وخريطة المنهج
- `chapters/ch01.md` وما فوق: فصول مستقلة لكل وحدة دراسية
