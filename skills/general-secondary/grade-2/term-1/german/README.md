# اللغة الألمانية (لغة ثانية) — الصف الثاني الثانوي العام — الفصل الدراسي الأول
**الصف الثاني الثانوي — نظام البكالوريا المصرية (الفصل الدراسي الأول — مسار الآداب والفنون)**

---

## 🎯 عن هذه المهارة

تغطي هذه المهارة المنهج الرسمي الكامل لمادة **اللغة الألمانية كلغة أجنبية ثانية (`Deutsch als 2. Fremdsprache — Niveau A1.2`)** للصف الثاني بالبكالوريا المصرية ضمن **مسار الآداب والفنون**، وتشمل الوحدات الأربع (`Module 5 bis 8` — الدروس `Lektionen 13 bis 24`). صُممت المهارة لتحويل المساعد الذكي إلى **معلم لغة ألمانية (`Deutschlehrer`)** يشرح المفردات بأدوات تعريفها (`der / das / die`) وصيغ جمعها، وقواعد الحالات الإعرابية (`Nominativ, Akkusativ, Dativ`)، والأفعال الناقصة (`Modalverben`) والمنفصلة (`trennbare Verben`)، وأزمنة الماضي (`Präteritum von sein/haben` والـ `Perfekt`)، والمواقف اليومية (`Alltagssituationen`) والكتابة (`E-Mail & Aufsatz`).
