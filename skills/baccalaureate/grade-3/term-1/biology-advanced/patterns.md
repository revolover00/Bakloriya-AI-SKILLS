# الملخص السريع ليلة الامتحان: الأحياء (مستوى متقدم) — الصف الثالث بكالوريا — الفصل الدراسي الأول (الجزء الأول)

- **الجهاز الهيكلي:** $206$ عظمة (المحوري $80$ والطرفي $126$)؛ وعدد القطع العضلية $= 	ext{خطوط } Z - 1$.
- **الهرمونات:** الكالسيتونين والباراثورمون لتنظيم الكالسيوم، والأنسولين والجلوكاجون لتنظيم الجلوكوز.


## استراتيجية الحل التدريجي
1. تحديد معطيات السؤال والمطلوب بدقة.
2. تطبيق القاعدة أو القانون المقرر من الفصول التفصيلية.
3. استبعاد البدائل الخاطئة مع التعليل العلمي أو اللغوي.
