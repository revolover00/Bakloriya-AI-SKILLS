## أولًا: مصطلحات الفصل الأول — البراهين الجبرية (`Algebraic Proofs`)

| المصطلح بالعربية | المصطلح بالإنجليزية | الصيغة / المعنى الرياضي |
|---|---|---|
| **نظرية ذات الحدين** | `Binomial Theorem` | $(a+b)^n = \sum_{r=0}^n {^nC_r} a^{n-r} b^r$ (عدد الحدود = $n+1$). |
| **الحد العام في مفكوك ذات الحدين** | `General Term` | $T_{r+1} = {^nC_r} a^{n-r} b^r$ (حيث مجموع الأسين يساوي $n$ دائمًا). |
| **مفكوك متعدد الحدود** | `Multinomial Expansion` | معامل $a^p b^q c^r$ في $(a+b+c)^n$ هو $\dfrac{n!}{p!q!r!}$ بشرط $p+q+r=n$. |
| **خوارزمية قسمة كثيرات الحدود** | `Polynomial Division` | $A(x) = B(x)Q(x) + R(x)$ حيث $\deg(R) < \deg(B)$ أو $R(x) = 0$. |
| **المقدار النسبي** | `Rational Expression` | كسر بسطه ومقامه كثيرتا حدود؛ الاختزال يتم للعوامل المضروبة فقط. |
| **الكسر المركب / المتصل** | `Complex / Continued Fraction` | كسر يحتوي بسطه أو مقامه على كسور؛ يُبسط بدءًا من أعمق كسر داخلي. |
| **المتطابقة** | `Identity` | مساواة جبرية صحيحة **لجميع قيم المتغير** المسموح بها (بخلاف المعادلة). |
| **الكسور الجزئية** | `Partial Fractions` | تفكيك كسر نسبي إلى مجموع كسور أبسط؛ نوجد المجاهيل بالتعويض بجذور عوامل المقام. |
| **متباينة الوسط الحسابي والهندسي** | `AM-GM Inequality` | لأي $a > 0, b > 0$: $\dfrac{a+b}{2} \ge \sqrt{ab}$، وتتحقق المساواة إذا وفقط إذا كان $a = b$. |

## ثانيًا: مصطلحات الفصل الثاني — المتتابعات (`Sequences`)

| المصطلح بالعربية | المصطلح بالإنجليزية | الصيغة / المعنى الرياضي |
|---|---|---|
| **المتتابعة الحسابية** | `Arithmetic Sequence` | $a_n = a + (n-1)d$ حيث الأساس $d = a_n - a_{n-1}$ والوسط الحسابي $2b = a+c$. |
| **مجموع المتتابعة الحسابية** | `Arithmetic Series Sum` | $S_n = \frac{n}{2}(a+l) = \frac{n}{2}[2a+(n-1)d]$ (تكون على الصورة $An^2+Bn$ بلا حد ثابت). |
| **المتتابعة الهندسية** | `Geometric Sequence` | $a_n = a r^{n-1}$ حيث الأساس $r = a_n / a_{n-1}$ والوسط الهندسي $b^2 = ac$. |
| **مجموع المتتابعة الهندسية** | `Geometric Series Sum` | $S_n = \dfrac{a(1-r^n)}{1-r}$ عند $r \ne 1$، و$S_n = na$ عند $r = 1$. |
| **رمز التجميع سيجما** | `Sigma Notation` ($\Sigma$) | $\sum_{k=1}^n c = nc$، $\sum_{k=1}^n k = \frac{1}{2}n(n+1)$، $\sum_{k=1}^n k^2 = \frac{1}{6}n(n+1)(2n+1)$، $\sum_{k=1}^n k^3 = [\frac{1}{2}n(n+1)]^2$. |
| **الحد العام من المجموع** | `General Term from Sum` | $a_1 = S_1$، و$a_n = S_n - S_{n-1}$ لكل $n \ge 2$. |
| **متتابعة الفروق** | `Sequence of Differences` | عند $b_k = a_{k+1} - a_k$ يكون $a_n = a_1 + \sum_{k=1}^{n-1} b_k$ لكل $n \ge 2$. |
| **علاقة التكرار الخطية** | `Linear Recurrence Relation` | $a_{n+1} = p a_n + q$؛ تُحل بإيجاد النقطة الثابتة $c = pc + q$ فتصبح $(a_n - c)$ هندسية أساسها $p$. |
| **الاستقراء الرياضي** | `Mathematical Induction` | برهان من 3 خطوات لإثبات صحة عبارة لكل عدد طبيعي $n$: الأساس ($n=1$) $\leftarrow$ الفرض ($n=k$) $\leftarrow$ الإثبات ($n=k+1$). |

## ثالثًا: مصطلحات الفصل الثالث — الأعداد المركبة والمعادلات (`Complex Numbers & Equations`)

| المصطلح بالعربية | المصطلح بالإنجليزية | الصيغة / المعنى الرياضي |
|---|---|---|
| **الوحدة التخيلية** | `Imaginary Unit` ($i$) | $i^2 = -1, \quad i^3 = -i, \quad i^4 = 1$ (نقسم الأس على $4$ ونأخذ الباقي). |
| **العدد المركب** | `Complex Number` | $z = a + bi$ حيث $a$ الجزء الحقيقي و$b$ الجزء التخيلي (العدد $b$ وحده بدون $i$). |
| **المرافق المركب** | `Complex Conjugate` | مرافق $a+bi$ هو $a-bi$، وحاصل ضربهما $(a+bi)(a-bi) = a^2 + b^2$ عدد حقيقي دائمًا. |
| **مميز المعادلة التربيعية** | `Discriminant` ($D$) | $D = b^2 - 4ac$: إذا $D>0$ جذران حقيقيان مختلفان؛ $D=0$ حقيقيان متساويان؛ $D<0$ مركبان مترافقان. |
| **العلاقة بين الجذرين والمعاملات** | `Vieta's Formulas` | في $ax^2+bx+c=0$: $\alpha+\beta = -\frac{b}{a}$، و$\alpha\beta = \frac{c}{a}$. |
| **نظرية الباقي** | `Remainder Theorem` | باقي قسمة $P(x)$ على $(x-a)$ هو $P(a)$، وعلى $(ax-b)$ هو $P(b/a)$. |
| **نظرية العوامل** | `Factor Theorem` | يكون $(x-a)$ عاملًا لـ $P(x)$ إذا وفقط إذا كان $P(a) = 0$. |
| **القسمة التركيبية** | `Synthetic Division` | طريقة مختصرة لقسمة كثيرة حدود على $(x-a)$ باستخدام المعاملات فقط (مع وضع $0$ للأس الناقص). |
| **الجذر التكعيبي التخيلي للواحد** | `Cube Root of Unity` ($\omega$) | $\omega^3 = 1$ و$1 + \omega + \omega^2 = 0$ (نقسم الأس على $3$ ونأخذ الباقي). |

## رابعًا: مصطلحات الفصل الرابع — الهندسة والمعادلات (`Geometry and Equations`)

| المصطلح بالعربية | المصطلح بالإنجليزية | الصيغة / المعنى الرياضي |
|---|---|---|
| **التقسيم الداخلي** | `Internal Division` | تقسيم $AB$ من الداخل بنسبة $m:n$: $P = \left(\frac{nx_1+mx_2}{m+n}, \frac{ny_1+my_2}{m+n}\right)$. |
| **التقسيم الخارجي** | `External Division` | تقسيم $AB$ من الخارج بنسبة $m:n$ ($m\ne n$): $Q = \left(\frac{-nx_1+mx_2}{m-n}, \frac{-ny_1+my_2}{m-n}\right)$. |
| **مركز ثقل المثلث** | `Centroid of a Triangle` | نقطة تلاقي المتوسطات: $G = \left(\frac{x_1+x_2+x_3}{3}, \frac{y_1+y_2+y_3}{3}\right)$. |
| **التوازي والتعامد لمستقيمين** | `Parallel & Perpendicular` | التوازي: $m_1 = m_2$ | التعامد: $m_1 \times m_2 = -1$. |
| **بُعد نقطة عن مستقيم** | `Point-to-Line Distance` | بُعد $(x_1, y_1)$ عن $ax+by+c=0$ هو $d = \dfrac{|ax_1+by_1+c|}{\sqrt{a^2+b^2}}$. |
| **مساحة المثلث بمعلومية الرؤوس** | `Area of Triangle` | $S = \frac{1}{2}|x_1(y_2-y_3) + x_2(y_3-y_1) + x_3(y_1-y_2)|$. |
| **معادلة الدائرة** | `Circle Equation` | القياسية: $(x-a)^2 + (y-b)^2 = r^2$ | العامة: $x^2+y^2+lx+my+n=0$ بشرط $r^2 > 0$. |
| **طول وتر الدائرة** | `Chord Length` | نصف الوتر $l = \sqrt{r^2 - d^2}$، وطول الوتر الكامل = **$2l = 2\sqrt{r^2 - d^2}$**. |
| **معادلة المماس عند نقطة على الدائرة** | `Tangent Line Equation` | للدائرة $x^2+y^2=r^2$ عند $(x_1, y_1)$ عليها: $x_1 x + y_1 y = r^2$. |
| **حزمة الدوائر والوتر المشترك** | `Pencil of Circles & Radical Axis` | $kC_1 + C_2 = 0$؛ عند $k = -1$ تعطي المستقيم المار بنقطتي التقاطع، وعند $k \ne -1$ تعطي دائرة مارة بنقطتي التقاطع. |
