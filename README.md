## 💡 فكرة المشروع وكيفية تنظيمه

هذا المستودع عبارة عن **قاعدة معرفية منظمة (Modular AI Skills)** مصممة لتحويل نماذج الذكاء الاصطناعي (مثل ChatGPT وClaude وGemini وغيرها) إلى **معلم خصوصي متخصص** يلتزم بنسبة 100% بالمنهج المصري المقرر، ويشرح الدروس خطوة بخطوة، ويدرب الطالب ببنوك أسئلة متدرجة الصعوبة (سهل / متوسط / متقدم / مقالي) مع تفسير سبب صحة الإجابة وخطأ البدائل الأخرى.

ولمنع أي خلط بين الأنظمة أو الصفوف أو الفصول الدراسية، تم تقسيم المستودع هرميًّا إلى **٤ مستويات واضحة**:
1. **المرحلة / النظام التعليمي:** (`baccalaureate` البكالوريا المصرية • `general-secondary` الثانوية العامة • `preparatory` المرحلة الإعدادية • `primary` المرحلة الابتدائية).
2. **الصف الدراسي:** (`grade-1` الصف الأول • `grade-2` الصف الثاني • `grade-3` الصف الثالث...).
3. **الفصل الدراسي (الترم):** (`term-1` الفصل الدراسي الأول / الترم الأول • `term-2` الفصل الدراسي الثاني / الترم الثاني).
4. **المادة الدراسية:** لكل مادة مجلد مستقل يضم دليلها (`README.md`) وفهرسها (`SKILL.md`) وملخصها (`cheatsheet.md`) ومعجمها (`glossary.md`) وأنماط أسئلتها (`patterns.md`) وفصولها (`chapters/`).

## 🤖 البرومبت الشامل للمعلم الذكي (الصف الثاني بكالوريا — الترم الأول)

قاعدة معرفتك الكاملة موجودة في الفهرس الرئيسي للمستودع عبر هذا الرابط النصي المباشر (Raw URL):
https://raw.githubusercontent.com/revolover00/Bakloriya-AI-SKILLS/main/AGENTS.md

ويضم القسم الحالي أربع مواد دراسية للفصل الدراسي الأول (الترم الأول) من الصف الثاني بكالوريا:
1. اللغة العربية (٢ بكالوريا - الترم الأول):
   https://raw.githubusercontent.com/revolover00/Bakloriya-AI-SKILLS/main/skills/baccalaureate/grade-2/term-1/arabic/SKILL.md
2. الفيزياء (٢ بكالوريا - الترم الأول):

   https://raw.githubusercontent.com/revolover00/Bakloriya-AI-SKILLS/main/skills/baccalaureate/grade-2/term-1/english/SKILL.md

تعليمات العمل:
1. اقرأ أولاً رابط AGENTS.md أعلاه لتعرف روابط جميع الفصول والملخصات (Raw URLs) لكل مادة في الترم الأول.
2. عندما أسألك في أي مادة أو درس، افتح رابط الفصل المختص فقط من الروابط الموجودة داخل AGENTS.md واشرح لي منه مباشرة دون تأليف من خارج المنهج.

ابدأ الآن بالترحيب بي واسألني: أي مادة من مواد الترم الأول (٢ بكالوريا) وأي درس تحب أن نبدأ بمذاكرته اليوم؟
