# أنماط الأسئلة المتكررة ومفاتيح الحل: الاقتصاد (مستوى متقدم) — الصف الثالث بكالوريا — الفصل الدراسي الثاني (الجزء الثاني)

# الملخص السريع ليلة الامتحان: الاقتصاد (مستوى متقدم) — الصف الثالث بكالوريا — الفصل الدراسي الثاني (الجزء الثاني)

- **مبادئ الموازنة الأربعة:** السنوية، الوحدة، العمومية، التوازن.
- **السهم مقابل السند:** حامل السهم شريك ومالك بعائد متغير، وحامل السند دائن بعائد فائدة ثابتة.


## استراتيجية الحل التدريجي
1. تحديد معطيات السؤال والمطلوب بدقة.
2. تطبيق القاعدة أو القانون المقرر من الفصول التفصيلية.
3. استبعاد البدائل الخاطئة مع التعليل العلمي أو اللغوي.
