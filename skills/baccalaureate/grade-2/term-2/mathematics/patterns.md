# أنماط الأسئلة ومصائد الامتحانات: الرياضيات — الصف الثاني بكالوريا — الفصل الدراسي الثاني (الفصول ٥–٨)

## 1. قاعدة السدس الشهيرة للمساحات

المساحة المحصورة بين منحنى بارابولا y = ax^2 + bx + c ومستقيم (أو بارابولا أخرى) يتقاطعان عند x = alpha و x = beta تساوي: S = (|a|/6) * (beta - alpha)^3.

## 2. التحويل الخطي للمتغير العشوائي Y = aX + b

• التوقع يتأثر بالضرب والجمع: E(aX + b) = a*E(X) + b.
• التباين يتأثر بمربع معامل الضرب فقط ولا يتأثر بالجمع: V(aX + b) = a^2 * V(X).
