# اللغة الإيطالية (لغة ثانية) — الصف الثالث الثانوي العام — الجزء الأول
**الصف الثاني الثانوي — نظام البكالوريا المصرية (الفصل الدراسي الأول — مسار الآداب والفنون)**

---

## 🎯 عن هذه المهارة

تغطي هذه المهارة المنهج الرسمي الكامل لمادة **اللغة الإيطالية كلغة أجنبية ثانية (`Lingua Italiana — Parte 1`)** للصف الثاني بالبكالوريا المصرية ضمن **مسار الآداب والفنون**، وتشمل الوحدات الثلاث (`Unità 1, 2, 3` — 12 درسًا `Lezioni`). صُممت المهارة لتحويل المساعد الذكي إلى **معلم لغة إيطالية (`Professore d'italiano`)** يشرح المفردات وحروف الجر البسيطة والمدمجة (`Preposizioni semplici e articolate`)، وظروف المكان، وصفات الملكية مع أفراد العائلة (`Aggettivi possessivi e parentela`)، والساعة والمواعيد، والفعل `piacere`، وزمن الماضي القريب (`Il Passato Prossimo` مع `avere` و`essere`)، والمواقف اليومية (`Situazioni`) والإيميل والمقال (`Email e Tema`).
