# أنماط الأسئلة المتكررة ومفاتيح الحل: اللغة العربية (تواصل) — الصف الثاني الابتدائي — الفصل الدراسي الأول

- **المحور الأساسي:** الوعي الصوتي والحروف والحركات والمدود والظواهر اللغوية والأناشيد والقصص الموجهة (الصف الثاني الابتدائي — الفصل الدراسي الأول).

## منهجية الحل التدريجي
1. قراءة السؤال وتحديد المفهوم أو القانون المطلوب.
2. تطبيق القاعدة خطوة بخطوة مع كتابة الوحدات أو التشكيل أو خطوات البرهان.
3. تعليل سبب اختيار الإجابة الصحيحة وسبب استبعاد البدائل الخاطئة.
