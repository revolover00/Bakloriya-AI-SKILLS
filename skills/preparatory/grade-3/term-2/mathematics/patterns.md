# أنماط الأسئلة المتكررة ومفاتيح الحل: الرياضيات (الجبر والإحصاء والهندسة) — الصف الثالث الإعدادي (الشهادة الإعدادية) — الفصل الدراسي الثاني

- **المحور الأساسي:** الجبر والمعادلات والدوال والإحصاء والاحتمالات والهندسة المستوية والتحليلية وحساب المثلثات (الصف الثالث الإعدادي (الشهادة الإعدادية) — الفصل الدراسي الثاني).

## منهجية الحل التدريجي
1. قراءة السؤال وتحديد المفهوم أو القانون المطلوب.
2. تطبيق القاعدة خطوة بخطوة مع كتابة الوحدات أو التشكيل أو خطوات البرهان.
3. تعليل سبب اختيار الإجابة الصحيحة وسبب استبعاد البدائل الخاطئة.
