## الإطار الذهني الأساسي (Core Frameworks)

### 1. الوصف الفيزيائي الكامل = قيمة عددية + وحدة (+ اتجاه إن كانت متجهة)
- **الكمية القياسية** (كتلة، زمن، مسافة، شغل، سرعة عددية): يكفي المقدار.
- **الكمية المتجهة** (إزاحة، سرعة متجهة، عجلة، قوة، وزن، زخم): المقدار **والاتجاه** معًا؛ الرقم والوحدة بدون اتجاه وصف ناقص.
- **استخدم هذا الاختبار سريعًا**: هل يكتمل وصف الكمية بالمقدار وحده؟ نعم → قياسية، لا → متجهة.

### 2. نوع الكمية يحدّد أسّ عامل التحويل (قاعدة ذهبية)
- طول → عامل^1، مساحة → عامل^2 (تربيع)، حجم → عامل^3 (تكعيب)، كثافة → كتلة^1 × حجم^-1.
- **قبل أي تعويض حدّد: طول أم مساحة أم حجم أم سرعة أم كثافة**، ثم اضبط الأس، ثم حوّل.

### 3. خريطة اختيار طريقة جمع سرعتين (حسب العلاقة بين الاتجاهين)
| العلاقة بين الاتجاهين | الطريقة | الناتج |
|---|---|---|
| نفس الخط ونفس الاتجاه | جمع المقدارين | في نفس الاتجاه |
| نفس الخط واتجاهان متضادان | الأكبر − الأصغر | مع اتجاه **الأكبر** |
| متعامدتان (90°) | فيثاغورس + ظا (تا) | مقدار + زاوية اتجاه |
| زاوية أيّة θ | قانون جيب التمام | مقدار + زاوية اتجاه |

### 4. السرعة النسبية = فرق متجهي وليس فرقًا عدديًا
- الصيغة المرجعية: **سرعة A بالنسبة إلى B = v⃗_A − v⃗_B** (الجسم المرصود ناقص الراصد).
- نفس الاتجاه → نأخذ الفرق؛ اتجاهان متضادان → المجموع؛ متعامدتان → وتر المثلث القائم.
- **ابدأ دائمًا بتحديد اتجاه كل متجه بالنسبة للراصد المطلوب**، لا تجمع الأرقام فورًا.

### 5. قاعدة المحور في التحليل (جا أم جتا؟)
- الزاوية مع **الأفقي** → الأفقية = v·جتا θ، الرأسية = v·جا θ.
- الزاوية مع **الرأسي** → اعكس: الرأسية = v·جتا θ، الأفقية = v·جا θ.
- **حدّد أولًا المحور الذي خرجت منه الزاوية** قبل اختيار الدالة؛ لا تبدّل بالحفظ.

### 6. المسار المائل = محصلة حركتين متعامدتين (وليس مجموعهما العددي)
- العبور والسحب / القارب والتيار / الطائرة والرياح: ارسم المثلث القائم.
- المطر يبدو مائلًا للراكب لأن حركة الراصد تدخل في وصف الحركة؛ ميل الخطوط لا يعني أن السقوط الحقيقي انحرف عن الرأسي.
