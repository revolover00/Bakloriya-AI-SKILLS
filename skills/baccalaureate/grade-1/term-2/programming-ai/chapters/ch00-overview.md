# نظرة عامة وخريطة المنهج: البرمجة والذكاء الاصطناعي — الصف الأول بكالوريا — الفصل الدراسي الثاني

يغطي **الوحدات ٨ إلى ١٣ (٣٣ درسًا، ص 108–218)** من كتاب البرمجة والذكاء الاصطناعي الرسمي للصف الأول الثانوي:
- **ch01 (الوحدتان ٨ و٩ — الشبكات وقواعد البيانات، ٨ دروس، ص 108–135):** شبكات الكمبيوتر (LAN/WAN)، عناوين IP وأسماء النطاقات DNS، بروتوكولات TCP/IP وHTTP/HTTPS، سرعة نقل البيانات، وقواعد البيانات العلائقية وSQL.
- **ch02 (الوحدتان ١٠ و١١ — تحليل البيانات والمحاكاة، ١٠ دروس، ص 136–167):** أنواع البيانات والتحليل الإحصائي، النمذجة والمحاكاة الحاسوبية، وقوائم الانتظار (Queues).
- **ch03 (الوحدة الثانية عشرة — البرمجة، ٥ دروس، ص 168–190):** الخوارزميات وخرائط التدفق، المتغيرات، الجمل الشرطية، الحلقات التكرارية، المصفوفات والدوال، وخوارزميات البحث الخطي والثنائي والترتيب.
- **ch04 (الوحدة الثالثة عشرة — الذكاء الاصطناعي التوليدي وتطوير الويب والألعاب، ١٢ درسًا، ص 191–218):** الذكاء الاصطناعي التوليدي، تطوير صفحات الويب بـ HTML وCSS وJavaScript، تطوير تطبيق اختبارات تفاعلي، وتطوير لعبة تكسير القوالب (*Brick Breaker*).
