# 📖 قاموس مصطلحات علم النفس (الفصل الدراسي الأول)
**الصف الثاني بكالوريا — مسار الآداب والفنون (الوحدات 1 إلى 3 — 12 درسًا)**

---

## أولًا: مصطلحات الوحدة الأولى — أساسيات علم النفس (الدروس `1-1` إلى `1-4`)

| المصطلح | المعنى الدقيق وفق المنهج | الدرس |
|---|---|---|
| **علم النفس** | الدراسة العلمية للسلوك الإنساني (الظاهر والعمليات الداخلية) بهدف وصفه وفهمه والتنبؤ به وضبطه. | `1-1` |
| **السلوك** | كل الأفعال الظاهرة والعمليات العقلية والانفعالية الداخلية التي تصدر عن الإنسان في المواقف المختلفة. | `1-1` |
| **الاستبطان** | منهج يصف فيه **الفرد نفسه** وخبراته الشعورية وأفكاره ومشاعره كما يشعر بها أثناء حدوثها. | `1-1` |
| **زمن الرجع (`Reaction Time`)** | الزمن الفاصل بين ظهور المثير وحدوث الاستجابة لدى الفرد. | `1-1` |
| **الخبرة الشعورية** | ما يعيه الفرد ويشعر به في اللحظة الحاضرة (موضوع دراسة **المدرسة البنائية** التي أسسها تيتشنر). | `1-1` |
| **اللاشعور** | الرغبات والدوافع والذكريات المكبوتة التي لا نعيها ولا نستدعيها بسهولة (المحرك الخفي للسلوك عند فرويد). | `1-1` |
| **تحقيق الذات** | ميل الإنسان الفطري إلى تطوير قدراته وبلوغ أفضل إمكاناته (محور **علم النفس الإنساني**). | `1-1` |
| **المثير (`Stimulus`)** | أي عامل **خارجي** (صوت، ضوء) أو **داخلي** (جوع، خوف، قلق، فكرة) ينشط الكائن الحي أو يؤثر في سلوكه. | `1-2` |
| **الاستجابة (`Response`)** | سلوك يرتبط بمثير معين ويصدر نتيجة التعرّض له (كل استجابة سلوك وليس كل سلوك استجابة). | `1-2` |
| **الأهداف الأربعة لعلم النفس** | **الوصف** (تسجيل ماذا ومتى وكم) $\leftarrow$ **الفهم** (تفسير لماذا) $\leftarrow$ **التنبؤ** (توقع بلا تدخل) $\leftarrow$ **الضبط** (تدخل لتعديل السلوك). | `1-2` |
| **المجالات النظرية** | فروع تهدف إلى **فهم السلوك وتفسيره** واكتشاف قوانينه دون تدخل علاجي مباشر (العام، المعرفي، الفسيولوجي، النمو، الاجتماعي، الفروق الفردية، الشخصية). | `1-3` |
| **المجالات التطبيقية** | فروع تستثمر القوانين النفسية في **التدخل وحل مشكلات الواقع** (الإكلينيكي/العيادي، الإرشادي، التربوي، الصناعي والتنظيمي). | `1-3` |
| **علم النفس الإكلينيكي مقابل الإرشادي** | **الإكلينيكي** لتشخيص وعلاج الاضطرابات النفسية المعقدة؛ بينما **الإرشادي** لمساعدة الأسوياء في المشكلات اليومية واتخاذ القرارات دون أوامر. | `1-3` |
| **الملاحظة العلمية وبطاقة الملاحظة** | متابعة منظمة ومحايدة للسلوك من الخارج، وتُسجل في بطاقة تحدد (الموقف، نوع السلوك، مدته، وتكراره). | `1-4` |
| **المنهج الارتباطي** | يدرس قوّة واتجاه العلاقة بين متغيرين دون تدخل (**وجود علاقة ارتباطية لا يعني السببية!**). | `1-4` |
| **المنهج التجريبي وشبه التجريبي** | **التجريبي:** يتحكم في المتغير المستقل ويقيس أثره على التابع مع تثبيت الدخيلة. **شبه التجريبي:** يُستخدم حين تمنع الأخلاق أو الواقع التجربة الكاملة. | `1-4` |

## ثانيًا: مصطلحات الوحدة الثانية — العمليات المعرفية (الدروس `2-1` إلى `2-4`)

| المصطلح | المعنى الدقيق وفق المنهج | الدرس |
|---|---|---|
| **الإحساس (`Sensation`)** | عملية **استقبال أوّلي خام** للمثيرات عبر أعضاء الحس التسع (الخمس الخارجية + الألم والضغط والتوازن والحركة). | `2-1` |
| **العتبة المطلقة / الفارقة / القصوى** | **المطلقة:** الحد الأدنى للإحساس بمثير · **الفارقة:** أقل فرق يُلاحظ بين مثيرين · **القصوى:** الحد الأقصى الذي **يؤذي ويؤلم** عضو الحس (وليس ذروة الوضوح!). | `2-1` |
| **الانتباه (`Attention`)** | عملية **اختيار (فلترة)** بعض المثيرات والتركيز عليها دون غيرها؛ وله **مدى** (كم مثيرًا في اللحظة) و**مدة** (كم من الوقت). | `2-2` |
| **الإدراك (`Perception`)** | عملية عقلية **لتفسير المثيرات وإعطائها معنى** («لا نستجيب للمواقف كما هي، بل كما نفسرها»). | `2-2` |
| **قوانين الجشطلت في الإدراك** | الشكل والأرضية · التقارب · التشابه · الغلق (تسهّل الفهم السريع لكنها قد تؤدي لتفسير غير دقيق أحيانًا). | `2-2` |
| **الخداع الإدراكي مقابل التحيز الإدراكي** | **الخداع:** سوء تفسير مصدره **خصائص المثير نفسه** (يحدث للجميع). **التحيز:** تفسير غير محايد مصدره **توقعات الفرد وأفكاره المسبقة**. | `2-2` |
| **الذاكرة (`Memory`)** | **عملية نشطة** (ليست مخزنًا جامدًا!) تمر بثلاث مراحل: **الترميز** (تحويل لمعنى) $\leftarrow$ **التخزين** (الاحتفاظ) $\leftarrow$ **الاسترجاع** (الاستدعاء). | `2-3` |
| **أنواع الذاكرة الثلاثة** | **الحسية** (أجزاء من الثانية إلى $4$ ثوانٍ، مرتبطة بالإحساس) · **قصيرة المدى** ($15\text{–}30$ ثانية، مرتبطة بالانتباه) · **طويلة المدى** (أيام لأعوام، مرتبطة بالإدراك وعمق المعالجة). | `2-3` |
| **التفكير النقدي مقابل الإبداعي** | **النقدي:** فحص الافتراضات والحجج والاستنباط (من العام للخاص) والاستقراء (من الجزئي للعام) والتفسير. **الإبداعي:** إنتاج حلول جديدة بمهارات **الطلاقة** (الكم) و**المرونة** (تنوع الزوايا) و**الأصالة** (الجِدّة). | `2-4` |
| **اللوزة الدماغية (`Amygdala`)** | مركز عصبي يطلق استجابات انفعالية فورية سريعة قبل اكتمال التحليل العقلي الواعي (تفسر التسرع تحت الغضب أو الخوف). | `2-4` |

## ثالثًا: مصطلحات الوحدة الثالثة — النمو والانفعالات (الدروس `3-1` إلى `3-4`)

| المصطلح | المعنى الدقيق وفق المنهج | الدرس |
|---|---|---|
| **النمو مقابل التغيّر** | **النمو:** تغيرات كمية وكيفية متكاملة **تزيد الأداء أو الفهم أو التكيف** (نحو النضج). **التغيّر:** أي تبدّل عبر الزمن قد يكون إيجابيًا أو سلبيًا أو محايدًا. | `3-1` |
| **النمو العضوي مقابل الوظيفي** | **العضوي (التكويني):** الطول والوزن والأعضاء. **الوظيفي:** نمو العمليات العقلية والانفعالية والاجتماعية. | `3-1` |
| **من العام إلى الخاص مقابل من البسيط للمركب** | **من العام للخاص:** محوره **الدقة** (تحريك الذراع كله ثم الأصابع). **من البسيط للمركب:** محوره **التعقيد** (إدراك ثم تحليل ثم استنتاج). | `3-1` |
| **البلوغ مقابل المراهقة** | **البلوغ:** **حدث بيولوجي** (نضج الغدد الجنسية) **يسبق المراهقة**. **المراهقة:** **عملية شاملة** ($12\text{–}19$ سنة) جسمية وعقلية وانفعالية واجتماعية. | `3-2` |
| **مراحل تكوين الهوية الثلاث** | $\text{الاستكشاف (تجريب الاهتمامات)} \leftarrow \text{الاختيار (المفاضلة)} \leftarrow \text{الالتزام (الثبات والدفاع عما اختاره)}$. | `3-2` |
| **الانفعال (`Emotion`)** | استجابة مركبة تشمل **ثلاثة مكونات في آنٍ واحد: معرفي + فسيولوجي + سلوكي**، وسببه $(\text{التفسير} + \text{الخبرة} + \text{الحالة الداخلية})$ وليس الموقف وحده. | `3-3` |
| **الانفعالات الأساسية مقابل المركبة** | **الأساسية:** فطرية تلقائية (فرح، حزن، خوف، غضب). **المركبة:** تحتاج لتفكير وخبرة وتفسير اجتماعي (الفخر، الغيرة، الخجل). | `3-3` |
| **التنظيم الانفعالي** | التعامل الواعي مع المشاعر (وليس كبتها!): **إعادة التفسير** (تغيير المعنى **قبل** اكتمال الانفعال) و**التحكم في الاستجابة** (إيقاف الفعل **بعد** الانفعال). | `3-3` |
| **التكيف النفسي والاستماع الفعّال** | **التكيف:** القدرة على مواجهة المشكلات والتعامل معها (لا تجنبها). **الاستماع الفعّال:** تركيز وإدراك للمعنى والمشاعر خلف الكلمات (لا مجرد السكوت). | `3-4` |
| **إدارة الضغوط مقابل المرونة النفسية** | **إدارة الضغوط:** **وقاية قبل** وقوع الضرر. **المرونة النفسية (`Resilience`):** **تعافٍ واستعادة التوازن بعد** الصدمة أو الفشل («مرنًا كالنخيل»). | `3-4` |
