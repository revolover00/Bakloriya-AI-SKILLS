# أنماط الأسئلة المتكررة ومفاتيح الحل: تكنولوجيا المعلومات والاتصالات (ICT) — الصف الخامس الابتدائي — الفصل الدراسي الثاني

- **المحور الأساسي:** مكونات الحاسب، الشبكات، الأمن الرقمي، البحث العلمي، البرمجة، والذكاء الاصطناعي (الصف الخامس الابتدائي — الفصل الدراسي الثاني).

## منهجية الحل التدريجي
1. قراءة السؤال وتحديد المفهوم أو القانون المطلوب.
2. تطبيق القاعدة خطوة بخطوة مع كتابة الوحدات أو التشكيل أو خطوات البرهان.
3. تعليل سبب اختيار الإجابة الصحيحة وسبب استبعاد البدائل الخاطئة.
