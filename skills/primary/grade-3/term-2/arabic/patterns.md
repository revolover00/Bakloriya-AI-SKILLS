# أنماط الأسئلة المتكررة ومفاتيح الحل: اللغة العربية (تواصل) — الصف الثالث الابتدائي — الفصل الدراسي الثاني

- **المحور الأساسي:** الوعي الصوتي والحروف والحركات والمدود والظواهر اللغوية والأناشيد والقصص الموجهة (الصف الثالث الابتدائي — الفصل الدراسي الثاني).

## منهجية الحل التدريجي
1. قراءة السؤال وتحديد المفهوم أو القانون المطلوب.
2. تطبيق القاعدة خطوة بخطوة مع كتابة الوحدات أو التشكيل أو خطوات البرهان.
3. تعليل سبب اختيار الإجابة الصحيحة وسبب استبعاد البدائل الخاطئة.
