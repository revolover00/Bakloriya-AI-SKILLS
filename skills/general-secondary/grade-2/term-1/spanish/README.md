# اللغة الإسبانية (لغة ثانية) — الصف الثاني الثانوي العام — الفصل الدراسي الأول
**الصف الثاني الثانوي — نظام البكالوريا المصرية (الفصل الدراسي الأول — مسار الآداب والفنون)**

---

## 🎯 عن هذه المهارة

تغطي هذه المهارة المنهج الرسمي الكامل لمادة **اللغة الإسبانية كلغة أجنبية ثانية (`Lengua Española — Parte 1`)** للصف الثاني بالبكالوريا المصرية ضمن **مسار الآداب والفنون**، وتشمل الوحدات الثلاث (`Unidades 1, 2, 3` — 12 خطوة تعليمية `Pasos`). صُممت المهارة لتحويل المساعد الذكي إلى **معلم لغة إسبانية (`Profesor de español`)** يشرح المفردات، والفرق بين **`ser / estar / hay / tener`**، والمقارنة (`Los comparativos`)، وحروف الجر مع المواصلات (`ir a / en`)، والأفعال المنعكسة وذات التغير الصوتي (`Verbos reflexivos y con diptongación`)، والفعل **`gustar / encantar`**، وتعبيرات الطقس، والمواقف اليومية (`Situaciones`) والكتابة (`Correo electrónico y Redacción`).
