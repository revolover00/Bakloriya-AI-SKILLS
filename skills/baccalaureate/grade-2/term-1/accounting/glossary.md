## أولًا: مصطلحات الوحدة الأولى — لماذا نتعلم المحاسبة؟

| المصطلح | التعريف الدقيق وفق المنهج |
|---|---|
| **المحاسبة (`Accounting`)** | عملية **تسجيل** المعاملات المالية و**تلخيصها** و**عرضها في صورة تقارير** لتحويل البيانات إلى معلومات ملائمة لاتخاذ القرار. |
| **الأصول (`Assets`)** | موارد اقتصادية تمتلكها المنشأة ويُتوقع أن تحقق منافع مستقبلية — تجيب عن سؤال: **«ماذا تملك المنشأة؟»**. |
| **الخصوم / الالتزامات (`Liabilities`)** | التزامات مالية على المنشأة تجاه أطراف خارجية — تجيب عن سؤال: **«ماذا عليها؟»**. |
| **حقوق الملكية (`Owner's Equity`)** | نصيب المالك في الأصول بعد استبعاد كل الخصوم — تجيب عن سؤال: **«ما نصيب المالك؟»**. |
| **قاعدة القيد المزدوج (`Double-Entry Rule`)** | كل معاملة مالية لها أثران متساويان وتُسجَّل بطرفين: **مدين ودائن بنفس القيمة**. |
| **المدين والدائن (`Debit & Credit`)** | **جانبا الحساب** — وليسا زيادة ونقصًا، ولا «جيدًا» و«سيئًا»؛ ويتحدد أثرهما حسب نوع الحساب. |
| **مبدأ الحيطة والحذر (`Prudence`)** | الاعتراف بالخسائر المحتملة مبكرًا، وعدم تسجيل الأرباح إلا عند تحققها فعليًا لمنع التفاؤل المضلل. |
| **مبدأ المقابلة (`Matching Principle`)** | ربط المصروفات بالإيرادات التي تحققت خلال نفس الفترة المحاسبية لضمان دقة قياس ربح الفترة. |
| **مبدأ الثبات (`Consistency`)** | استخدام نفس السياسات والطرق المحاسبية عبر الفترات لإتاحة المقارنة العادلة. |
| **أساس الاستحقاق (`Accrual Basis`)** | تسجيل الإيرادات والمصروفات عند **تحققها أو حدوثها** بغض النظر عن توقيت التحصيل أو السداد النقدي. |
| **الأساس النقدي (`Cash Basis`)** | تسجيل الإيرادات والمصروفات فقط عند **استلام النقدية أو دفعها فعليًا**. |

## ثانيًا: مصطلحات الوحدة الثانية — القيد المزدوج ودفاتر الأستاذ

| المصطلح | التعريف الدقيق وفق المنهج |
|---|---|
| **دفتر اليومية العامة (`General Journal`)** | أول خطوة بعد تحليل المعاملة؛ تُسجَّل فيه المعاملات **بترتيب زمني** متسلسل. |
| **دفتر الأستاذ (`Ledger`)** | السجل الشامل الذي ينظم ما سجلته اليومية **منهجيًا حسب الحساب** (حساب مستقل لكل عنصر). |
| **الترحيل (`Posting`)** | نقل أثر القيد من دفتر اليومية إلى حساب الأستاذ المختص. |
| **ترصيد الحساب (`Balancing`)** | حساب الفرق بين مجموع الجانب المدين ومجموع الجانب الدائن في نهاية الفترة. |
| **الإيرادات (`Revenues`)** | ما تكتسبه المنشأة من نشاطها؛ تزيد حقوق الملكية ولذلك **تزيد في الجانب الدائن**. |
| **المصروفات (`Expenses`)** | تكاليف تُنفق في سبيل النشاط؛ تنقص حقوق الملكية ولذلك **تزيد في الجانب المدين**. |
| **المسحوبات (`Drawings`)** | ما يسحبه المالك لاستخدامه الشخصي؛ تنقص حقوق الملكية ولذلك **تزيد في الجانب المدين** وتُطرح من رأس المال. |

## ثالثًا: مصطلحات الوحدة الثالثة — دفاتر اليومية المساعدة

| المصطلح | التعريف الدقيق وفق المنهج |
|---|---|
| **دفاتر اليومية المساعدة (`Subsidiary Journals`)** | دفاتر متخصصة (دفاتر القيد الأولي) تُجمّع المعاملات المتشابهة قبل ترحيلها إلى الأستاذ — تعزز الكفاءة والدقة والرقابة. |
| **المستند الأصلي (`Source Document`)** | دليل الإثبات الذي تبدأ به كل معاملة (فاتورة، إشعار مدين/دائن، إيصال، سند دفع). |
| **دفتر يومية المبيعات (`Sales Journal`)** | مخصص لتسجيل **المبيعات الآجلة للبضائع فقط** (لا تُسجَّل فيه المبيعات النقدية ولا بيع الأصول الثابتة). |
| **دفتر يومية المشتريات (`Purchases Journal`)** | مخصص لتسجيل **المشتريات الآجلة للبضائع بغرض إعادة البيع فقط** (الأصول الثابتة تُسجَّل في اليومية العامة). |
| **إشعار دائن (`Credit Note`)** | مستند يُصدَر **للعميل** عند رد بضاعة مباعة له — وهو مستند دفتر **مردودات المبيعات**. |
| **إشعار مدين (`Debit Note`)** | مستند يُرسَل **للمورد** عند رد بضاعة مشتراة منه — وهو مستند دفتر **مردودات المشتريات**. |
| **الخصم التجاري (`Trade Discount`)** | تخفيض في السعر المدرج بقائمة الأسعار — **لا يُسجَّل في الدفاتر أبدًا**، ويُقيَّد الصافي فقط. |
| **الخصم النقدي (`Cash Discount`)** | تخفيض مشروط بالسداد المبكر — **يُسجَّل صراحةً في الدفاتر**: عند البائع «خصم مسموح به» (مصروف/مدين)، وعند المشتري «خصم مكتسب» (إيراد/دائن). |
| **دفتر النقدية (`Cash Book`)** | يعمل **كدفتر يومية ودفتر أستاذ في آنٍ واحد** للنقدية والبنك، ولذلك لا يُفتح لهما حساب أستاذ منفصل. |
| **دفتر المصروفات النثرية (`Petty Cash Book`)** | دفتر مخصص للمدفوعات الصغيرة المتكررة (كثيرة العدد ضئيلة القيمة) بأعمدة تحليلية يُرحَّل إجمالي كل عمود منها. |

## رابعًا: مصطلحات الوحدة الرابعة — ميزان المراجعة وتصحيح الأخطاء

| المصطلح | التعريف الدقيق وفق المنهج |
|---|---|
| **ميزان المراجعة (`Trial Balance`)** | كشف بأرصدة كل الحسابات المفتوحة في الأستاذ في عمودين (مدين ودائن)؛ وهو **أداة رقابية** قبل القوائم المالية وليس قائمة مالية. |
| **الأخطاء المؤثرة على التوازن** | أخطاء تخالف قاعدة التأثير الثنائي (مثل التسجيل من جانب واحد، الترحيل غير المتساوي، خطأ الجمع، وضع الرصيد في العمود العكسي) فتجعل الإجماليين غير متساويين. |
| **الأخطاء غير المؤثرة (الخفية)** | أخطاء سُجِّل فيها الجانبان بنفس القيمة ولكن بشكل غير صحيح، فلا يكشفها ميزان المراجعة (السهو الكامل، خطأ التوجيه الفني، الخطأ في اسم الحساب الشخصي، الخطأ المتكافئ). |
| **خطأ التوجيه المحاسبي / الفني (`Error of Principle`)** | تسجيل العملية في فئة حساب غير صحيحة (مثل الخلط بين المصروف الإيرادي والمصروف الرأسمالي كاعتبار شراء معدات ضمن المشتريات). |
| **الخطأ المتكافئ (`Compensating Error`)** | خطآن مستقلان بنفس القيمة في جانبين مختلفين يلغي أحدهما أثر الآخر بالصدفة. |
| **حساب التسوية المعلّق (`Suspense Account`)** | حساب مؤقت يُدرج في الجانب الأصغر لاستيعاب الفرق لحين اكتشاف الخطأ؛ وهو **إشارة إلى خطأ وليس حلًّا له**. |
| **ميزان المراجعة المعدَّل (`Adjusted Trial Balance`)** | ميزان يُعد بعد إجراء قيود التصحيح وإقفال حساب التسوية المعلّق بحيث يصبح رصيده صفرًا. |

## خامسًا: مصطلحات الوحدة الخامسة — القوائم المالية للمنشأة الفردية

| المصطلح | التعريف الدقيق وفق المنهج |
|---|---|
| **حساب المتاجرة (`Trading Account`)** | حساب ختامي يقيس **مجمل الربح** ويركز **فقط على شراء وبيع البضاعة**. |
| **تكلفة البضاعة المباعة (`COGS`)** | $\text{مخزون أول المدة} + \text{المشتريات} - \text{مخزون آخر المدة}$. |
| **مجمل الربح (`Gross Profit`)** | $\text{إيراد المبيعات} - \text{تكلفة البضاعة المباعة}$ (يقيس كفاءة النشاط التجاري الأساسي قبل المصروفات التشغيلية). |
| **حساب الأرباح والخسائر (`Profit & Loss Account`)** | يبدأ بمجمل الربح المرحَّل ويُخصم منه جميع المصروفات التشغيلية (إيجار، رواتب، إهلاك، ديون معدومة) للوصول إلى **صافي الربح**. |
| **المصروف المستحق (`Accrued Expense`)** | منفعة استُهلكت خلال الفترة ولم تُدفع بعد — **يزيد المصروف** (ينقص الربح) و**ينشئ التزامًا متداولًا**. |
| **المصروف المدفوع مقدمًا (`Prepaid Expense`)** | مبلغ دُفع نقدًا ولم تُستهلك منفعته بعد (يخص فترة قادمة) — **ينقص المصروف** (يزيد الربح) و**يُدرج كأصل متداول**. |
| **الإهلاك (`Depreciation`)** | توزيع تكلفة الأصل غير المتداول على عمره الإنتاجي تطبيقًا لمبدأ المقابلة — **مصروف غير نقدي**. |
| **مجمع الإهلاك (`Accumulated Depreciation`)** | إجمالي الإهلاك المتراكم عبر السنوات؛ يُطرح من تكلفة الأصل في قائمة المركز المالي لإظهار **صافي القيمة الدفترية**. |
| **الديون المعدومة (`Bad Debts`)** | دين على عميل تأكد عدم إمكانية تحصيله؛ يُعالج كمصروف في الأرباح والخسائر ويُخصم من رصيد المدينين. |
| **قائمة المركز المالي (`Statement of Financial Position`)** | قائمة تعرض الوضع المالي للمنشأة (الأصول والخصوم وحقوق الملكية) **في تاريخ محدد**، وليست قائمة أداء. |
| **رأس المال آخر الفترة (`Closing Capital`)** | $\text{رأس المال أول الفترة} + \text{صافي الربح} - \text{المسحوبات}$. |
