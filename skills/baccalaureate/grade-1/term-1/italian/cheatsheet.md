# الملخص السريع ليلة الامتحان: اللغة الإيطالية (لغة ثانية — Progetto italiano Junior 1) — الصف الأول بكالوريا — الفصل الدراسي الأول

- **أدوات التعريف المذكرة:** `lo / gli` مع (`s+ساكن, z, ps, gn, x, y`)، و`l' / gli` مع المتحرك، و`il / i` مع الساكن.
- **أدوات التعريف المؤنثة:** `la / le` مع الساكن، و`l' / le` مع المتحرك.
- **أدوات النكرة:** `un, uno, una, un'`.
