# قاموس المصطلحات: البرمجة والذكاء الاصطناعي — الصف الثاني بكالوريا — الفصل الدراسي الثاني (الفصول ٥–٧)

| المصطلح | التعريف والشرح المنهجي |
|---|---|
| **تنقية البيانات (Data Cleaning)** | معالجة القيم المفقودة (Missing Values) والقيم المتطرفة (Outliers) والتكرارات قبل التحليل. |
| **واجهة برمجة التطبيقات (Web API)** | واجهة قياسية تتيح للبرمجيات تبادل البيانات عبر الويب (غالبًا بصيغة JSON). |
| **القيمة الاحتمالية (p-value)** | احتمال الحصول على النتيجة الملاحظة أو أشد منها تطرفًا تحت افتراض صحة الفرض الصفري H0. |
| **فرط التخصيص (Overfitting)** | حفظ النموذج لبيانات التدريب وضوضائها مما يضعف قدرته على التعميم على بيانات الاختبار الجديدة. |
| **نماذج اللغة الكبيرة (LLMs)** | نماذج ذكاء اصطناعي توليدي مبنية على معمارية المحولات (Transformer) وآلية الانتباه الذاتي (Self-Attention). |
