# أنماط الأسئلة المتكررة ومفاتيح الحل: الأحياء والجيولوجيا (علمي علوم) — الصف الثالث الثانوي العام — الفصل الدراسي الثاني (الجزء الثاني)

- **المحور الأساسي:** الدعامة والحركة والهرمونات والتكاثر والمناعة والبيولوجيا الجزيئية DNA/RNA، ومبادئ الجيولوجيا والمعادن والصخور (الفصل الدراسي الثاني (الجزء الثاني)).

## منهجية الحل التدريجي
1. قراءة السؤال وتحديد المفهوم أو القانون المطلوب.
2. تطبيق القاعدة خطوة بخطوة مع كتابة الوحدات أو التشكيل أو خطوات البرهان.
3. تعليل سبب اختيار الإجابة الصحيحة وسبب استبعاد البدائل الخاطئة.
