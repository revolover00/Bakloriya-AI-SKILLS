# ⚡ الملخص المكثف ليلة الامتحان — الرياضيات (الفصل الدراسي الأول)
**الصف الثاني بكالوريا — قوانين وتحذيرات الفصول الأربعة (88 بندًا)**

---

## 1️⃣ الفصل الأول: البراهين الجبرية (`1-1` إلى `1-16`)

| الموضوع | القانون الأساسي | التحذير الامتحاني الأهم |
|---|---|---|
| **ذات الحدين $(a+b)^n$** | $T_{r+1} = {^nC_r} a^{n-r} b^r$ | عدد الحدود $= n+1$، مجموع الأسين $= n$، و${^nC_r} = {^nC_{n-r}}$. |
| **متعدد الحدود $(a+b+c)^n$** | معامل $a^p b^q c^r$ هو $\dfrac{n!}{p!q!r!}$ | تأكد أولًا أن $p+q+r = n$، وارفع المعاملات العددية داخل الأقواس لأسسها. |
| **قسمة كثيرات الحدود** | $A = B \cdot Q + R \implies B = \dfrac{A - R}{Q}$ | رتب تنازليًا، اترك مكانًا ($0x^k$) للأس الناقص، وتوقف عندما $\deg(R) < \deg(B)$. |
| **المقادير النسبية** | الاختزال للعوامل المضروبة فقط | القيم المستبعدة هي التي تصفر **أي مقام أصلي** حتى لو اختفى بعد الاختزال. |
| **الكسور الجزئية والمتطابقات** | نعوض بجذور عوامل المقام | في إثبات المتطابقات **ممنوع نقل الحدود بين الطرفين**. |
| **النسب المتساوية** | إذا $\dfrac{a}{b}=\dfrac{c}{d}=\dfrac{e}{f}=k \implies a=bk, c=dk, e=fk$ | استخدم ثابتًا واحدًا $k$ لجميع النسب المتساوية. |
| **متباينة $AM\text{-}GM$** | $\dfrac{a+b}{2} \ge \sqrt{ab} \iff a+b \ge 2\sqrt{ab}$ | الشرط الإلزامي: **$a > 0, b > 0$**، والمساواة عند **$a = b$**. |

## 2️⃣ الفصل الثاني: المتتابعات (`2-1` إلى `2-26`)

| الموضوع | القانون الأساسي | التحذير الامتحاني الأهم |
|---|---|---|
| **المتتابعة الحسابية** | $a_n = a + (n-1)d, \quad a_q - a_p = (q-p)d$<br>$S_n = \frac{n}{2}(a+l) = \frac{n}{2}[2a+(n-1)d]$ | الوسط الحسابي $2b = a+c$. صيغة $S_n$ على الشكل $An^2 + Bn$ **بدون حد ثابت**. |
| **المتتابعة الهندسية** | $a_n = a r^{n-1}$<br>$S_n = \dfrac{a(1-r^n)}{1-r}$ ($r \ne 1$) | الوسط الهندسي $b^2 = ac$. في الحد العام الأس $n-1$، وفي المجموع الأس $n$. عند $r=1$ يكون $S_n = na$. |
| **قوانين التجميع $\Sigma$** | $\sum_{k=1}^n c = nc, \quad \sum_{k=1}^n k = \frac{1}{2}n(n+1)$<br>$\sum_{k=1}^n k^2 = \frac{1}{6}n(n+1)(2n+1)$<br>$\sum_{k=1}^n k^3 = \left[\frac{1}{2}n(n+1)\right]^2$ | $\Sigma$ **لا يتوزع على الضرب** ($\sum a_k b_k \ne \sum a_k \sum b_k$)؛ فك الأقواس أولًا. |
| **من $S_n$ إلى $a_n$** | $a_1 = S_1, \quad a_n = S_n - S_{n-1}$ ($n \ge 2$) | مجموع الحدود من $p$ إلى $q$ هو **$S_q - S_{p-1}$** (وليس $S_q - S_p$). |
| **متتابعة الفروق والتكرار** | $a_n = a_1 + \sum_{k=1}^{n-1} b_k$<br>$a_{n+1} = pa_n + q \implies c = pc + q$ | في متتابعة الفروق الحد الأعلى للسيجما هو **$n-1$**. |
| **الاستقراء الرياضي** | (1) $n=1$ $\leftarrow$ (2) فرض $n=k$ $\leftarrow$ (3) إثبات $n=k+1$ | إتمام خطوة $k+1$ بدون استعمال الفرض يجعل البرهان **باطلًا**. |

## 3️⃣ الفصل الثالث: الأعداد المركبة والمعادلات (`3-1` إلى `3-20`)

| الموضوع | القانون الأساسي | التحذير الامتحاني الأهم |
|---|---|---|
| **الأعداد المركبة والجذور السالبة** | $i^2 = -1, \; i^3 = -i, \; i^4 = 1$<br>$(a+bi)(a-bi) = a^2 + b^2$ | الجزء التخيلي لـ $a+bi$ هو **$b$ فقط** بدون $i$. عند ضرب جذور سالبة **حوّل لـ $i$ أولًا**: $\sqrt{-a}\sqrt{-b} = -\sqrt{ab}$. |
| **المميز والعلاقة بين الجذرين** | $D = b^2 - 4ac$<br>$\alpha+\beta = -\frac{b}{a}, \quad \alpha\beta = \frac{c}{a}$ | عند $D < 0$ للمعادلة **جذران مركبان مترافقان**. تكوين المعادلة: $x^2 - (\alpha+\beta)x + \alpha\beta = 0$. |
| **الباقي والعوامل** | باقي قسمة $P(x)$ على $(x-a)$ هو $P(a)$<br>$(x-a)$ عامل $\iff P(a) = 0$ | عند القسمة على مقدار من الدرجة الثانية نفرض الباقي خطيًا **$ax+b$**. |
| **المعادلة التكعيبية و$\omega$** | $\alpha+\beta+\gamma = -\frac{b}{a}, \; \alpha\beta+\beta\gamma+\gamma\alpha = \frac{c}{a}, \; \alpha\beta\gamma = -\frac{d}{a}$<br>$\omega^3 = 1, \quad 1+\omega+\omega^2 = 0$ | إذا كانت المعاملات حقيقية وكان $a+bi$ جذرًا، فإن مرافقه $a-bi$ جذر أيضًا. |

## 4️⃣ الفصل الرابع: الهندسة والمعادلات (`4-1` إلى `4-26`)

| الموضوع | القانون الأساسي | التحذير الامتحاني الأهم |
|---|---|---|
| **التقسيم والمسافة ومركز الثقل** | داخلي: $\dfrac{nA+mB}{m+n}$ | خارجي: $\dfrac{-nA+mB}{m-n}$<br>مركز ثقل المثلث: $\left(\dfrac{x_1+x_2+x_3}{3}, \dfrac{y_1+y_2+y_3}{3}\right)$ | في التقسيم الضرب متقاطع دائمًا. الانعكاس في محور $x$ يغير إشارة $y$. |
| **المستقيم والبُعد والمساحة** | التوازي: $m_1=m_2$ | التعامد: $m_1 m_2 = -1$<br>$d = \dfrac{|ax_1+by_1+c|}{\sqrt{a^2+b^2}}$<br>$S = \frac{1}{2}|x_1(y_2-y_3)+x_2(y_3-y_1)+x_3(y_1-y_2)|$ | رتب معادلة المستقيم $ax+by+c=0$ أولًا قبل قراءة $a,b,c$. |
| **الدائرة والوتر والمماس** | $(x-a)^2 + (y-b)^2 = r^2$ ($r^2 > 0$)<br>نصف الوتر $l = \sqrt{r^2-d^2} \implies \text{الوتر} = 2l$<br>المماس عند $(x_1,y_1)$ على الدائرة: $x_1 x + y_1 y = r^2$ | مماسة محور السينات $\implies r = |b|$، ومماسة الصادات $\implies r = |a|$. لإيجاد نقطتي تقاطع مستقيم ودائرة عوّض بالـ $x$ في **معادلة المستقيم** لا الدائرة! |
| **علاقة دائرتين وحزمة الدوائر** | تماس خارجي: $d = r_1 + r_2$ | تماس داخلي: $d = |r_1 - r_2|$<br>حزمة الدوائر: $kC_1 + C_2 = 0$ | عند $k = -1$ نحصل على **المستقيم المار بنقطتي التقاطع**؛ وعند $k \ne -1$ نقسم على $(k+1)$ لإيجاد مركز الدائرة الجديدة. |
