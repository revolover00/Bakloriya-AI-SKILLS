# أنماط المسائل وطرق الحل القياسية (Patterns) — فيزياء ٢ بكالوريا

يجمع هذا الملف قوالب الحل الحرفية المعتمدة في كتاب الصف الثاني الثانوي (٢ بكالوريا) لكل فئة من المسائل.

---

## 1. نمط تحليل المتجهات والرحلات المركبة *(ch00, ch01)*
**متى يُستخدم:** جسم يتحرك على مراحل متتالية بزوايا مختلفة، أو قوة/سرعة مائلة بزاوية $\theta$.
**الخطوات:**
1. طبّق القاعدة المعتمدة: **«المحور الذي تصنع معه الزاوية $\theta$ يأخذ $\cos\theta$ والآخر يأخذ $\sin\theta$»**.
2. احسب المركبات الأفقية والرأسية لكل مرحلة مع مراعاة الإشارات (شرق/شمال $+$، غرب/جنوب $-$):
   $$\Delta d_x = \sum v_{xi}\,t_i \quad,\quad \Delta d_y = \sum v_{yi}\,t_i$$
3. الإزاحة الكلية والمحصلة:
   $$\Delta d_T = \sqrt{(\Delta d_x)^2 + (\Delta d_y)^2} \quad,\quad \alpha = \tan^{-1}\!\left(\frac{|\Delta d_y|}{|\Delta d_x|}\right)$$
**المفاضلات والتنبيهات:** لا تجمع المسافات بالفيثاغورس؛ المسافة الكلية جمع جبري $\sum s_i$ بينما الإزاحة جمع اتجاهي.

## 2. نمط عبور النهر والقطار والمطر (السرعة النسبية) *(ch01)*
**متى يُستخدم:** قارب يعبر نهرًا له تيار، طائرة في رياح، أو راكب قطار يرى المطر مائلًا.
**الخطوات:**
- **عبور النهر عموديًا:**
  1. زمن العبور يُحسب **حصريًا** من عرض النهر $w$ وسرعة القارب العمودية $v_{\text{boat}}$: $t = \frac{w}{v_{\text{boat}}}$.
  2. مسافة الانجراف مع التيار: $d_{\text{drift}} = v_{\text{current}} \times t$.
  3. السرعة المحصلة: $v_T = \sqrt{v_{\text{boat}}^2 + v_{\text{current}}^2}$، وزاوية الانحراف $\tan\theta = \frac{v_{\text{current}}}{v_{\text{boat}}}$.
- **القطار والمطر:**
  - المطر يسقط رأسيًا بسرعة $v_R$ والقطار يتحرك أفقيًا بسرعة $v_A$، فيرى الراكب المطر مائلًا بزاوية $\theta$ مع الرأسي:
    $$\tan\theta = \frac{v_A}{v_R}$$

## 3. نمط اختيار معادلة الحركة وميل/مساحة المنحنيات *(ch02)*
**متى يُستخدم:** حركة في خط مستقيم بعجلة منتظمة أو منحنيات $(d\text{–}t)$، $(v\text{–}t)$، $(a\text{–}t)$.
**الخطوات:**
- حدد المتغير الغائب من المتغيرات الخمسة $(v_0, v, a, d, t)$:
  - غاب $d$ $\leftarrow$ $v = v_0 + at$
  - غاب $v$ $\leftarrow$ $d = v_0 t + \frac{1}{2}at^2$
  - غاب $t$ $\leftarrow$ $v^2 = v_0^2 + 2ad$
  - غاب $a$ $\leftarrow$ $d = \left(\frac{v_0 + v}{2}\right)t$
- في منحنى $(v\text{–}t)$: **الميل** $= a$، و**المساحة الهندسية تحت المنحنى** (مثلثات + مستطيلات + أشباه منحرف) $=$ الإزاحة $d$.

## 4. نمط المقذوف الأفقي *(ch03)*
**متى يُستخدم:** جسم ينطلق أفقيًا ($v_{0y} = 0$) من حافة مبنى أو طائرة على ارتفاع $h$.
**الخطوات:**
1. **المحور الرأسي أولًا:** استخرج زمن السقوط من الارتفاع وحده: $t = \sqrt{\frac{2h}{g}}$، والسرعة الرأسية $v_y = gt$.
2. **المحور الأفقي ثانيًا:** المدى الأفقي $x = v_0 t$، والسرعة الأفقية ثابتة $v_x = v_0$.
3. **السرعة الكلية لحظة الاصطدام:** $v = \sqrt{v_0^2 + (gt)^2}$ (أو مباشرة بحفظ الطاقة: $v = \sqrt{v_0^2 + 2gh}$).

---

## 5. نمط المقذوف بزاوية (أرض–أرض أو مبنى–منصة) *(ch04)*
**متى يُستخدم:** قذف بسرعة $v_0$ وزاوية $\theta$ مع الأفقي.
**الخطوات:**
1. حلّل السرعة الابتدائية: $v_{0x} = v_0\cos\theta$ (ثابتة)، $v_{0y} = v_0\sin\theta$.
2. **حالة أرض–أرض:**
   $$t_{\text{up}} = \frac{v_{0y}}{g} \quad,\quad T = 2t_{\text{up}} \quad,\quad h_{\max} = \frac{v_{0y}^2}{2g} \quad,\quad R = v_{0x}T$$
3. **حالة الإطلاق من مبنى ارتفاعه $h_{\text{build}}$ إلى منصة ارتفاعها $h$:**
   - أقصى ارتفاع عن الأرض: $H = h_{\text{build}} + \frac{(v_0\sin\theta)^2}{2g}$.
   - زمن الوصول للمنصة:
     $$T = \frac{v_0\sin\theta + \sqrt{(v_0\sin\theta)^2 + 2g(h_{\text{build}} - h)}}{g}$$

## 6. نمط اتزان العزوم والروافع *(ch05)*
**متى يُستخدم:** قضيب أو باب أو رافعة تحت تأثير قوى متعددة حول محور ارتكاز.
**الخطوات:**
1. أي قوة يمر خط عملها بمحور الدوران عزمها $= 0$ فورًا.
2. احسب ذراع كل قوة عموديًا: $d = L\sin\theta \implies M = FL\sin\theta$.
3. أعطِ إشارة $(+)$ للدوران عكس عقارب الساعة و$(-)$ لمع عقارب الساعة.
4. عند الاتزان الدوراني: $\sum M_{\text{ccw}} = \sum M_{\text{cw}} \implies F_1 d_1 = F_2 d_2$.

## 7. نمط اتزان الجسم المعلق بحبلين (المتماثلين والمختلفين) *(ch06)*
**متى يُستخدم:** مصباح أو لافتة وزنها $mg$ معلقة بحبلين يصنعان زاويتين مع الأفقي.
**الخطوات:**
- **حبلان متماثلان بزاوية $\theta$ مع الأفقي:**
  $$T_1 = T_2 = T \quad,\quad 2T\sin\theta = mg \implies T = \frac{mg}{2\sin\theta}$$
- **حبلان مختلفان بزاويتين $\theta_1, \theta_2$ مع الأفقي:**
  1. اتزان أفقي: $T_1\cos\theta_1 = T_2\cos\theta_2 \implies T_1 = T_2\frac{\cos\theta_2}{\cos\theta_1}$
  2. اتزان رأسي: $T_1\sin\theta_1 + T_2\sin\theta_2 = mg$ (عوّض عن $T_1$ واحسب $T_2$).
  *(تذكّر: الحبل صاحب الزاوية الأكبر مع الأفقي — أي الأقرب للرأسي — يحمل شدًا أكبر).*

## 8. نمط الشغل والقدرة والكفاءة ومخطط سانكي *(ch07)*
**متى يُستخدم:** رافعة أو محرك يسحب أو يرفع كتلة بسرعة منتظمة أو خلال زمن $t$.
**الخطوات:**
1. الشغل المبذول: $W = Fd\cos\theta$ (ولرفع كتلة رأسيًا بسرعة منتظمة: $W_{\text{useful}} = mgh$).
2. القدرة المفيدة: $P_{\text{useful}} = \frac{W_{\text{useful}}}{t} = mgv$.
3. الكفاءة: $\eta = \frac{P_{\text{useful}}}{P_{\text{in}}} \times 100\%$، والقدرة المهدرة $P_{\text{wasted}} = P_{\text{in}} - P_{\text{useful}}$.

## 9. نمط التصادمات الأربعة ومعامل الارتداد *(ch08, ch09, ch10)*
**متى يُستخدم:** اصطدام جسمين، ارتداد كرة عن حائط، أو انفجار جسم ساكن.
**الخطوات:**
1. **حدد اتجاهًا موجبًا** قبل كتابة أي رقم؛ أي سرعة معاكسة تأخذ إشارة سالبة $(-)$.
2. اختر النموذج المناسب:
   - **ارتداد عن حائط (جسم واحد):** $\bar{F}\,\Delta t = \Delta P = m(v_f - v_i)$ (مع عكس إشارة $v_f$).
   - **تصادم مع التحام ($e=0$):** $m_A v_A + m_B v_B = (m_A + m_B)v'$.
   - **انفجار جسم ساكن:** $0 = m_1 v_1 + m_2 v_2 \implies m_1 v_1 = -m_2 v_2$.
   - **تصادم بمعلومية معامل الارتداد $e$:** حُل المعادلتين معًا:
     $$m_A v_A + m_B v_B = m_A v_A' + m_B v_B'$$
     $$v_B' - v_A' = -e(v_B - v_A)$$
   - **تصادم ثنائي الأبعاد (انحراف بزاوية):** طبّق حفظ كمية التحرك على المحورين: $\sum P_x$ محفوظ و$\sum P_y = 0$.
3. لحساب **الطاقة الحركية المفقودة**: $\Delta E_k = E_{k,\text{before}} - E_{k,\text{after}}$.

## 10. نمط الحركة الدائرية الرأسية والحالة الحرجة *(ch12)*
**متى يُستخدم:** كرة مربوطة بخيط أو دلو ماء أو عربة ملاهي في مسار دائري رأسي نصف قطره $r$.
**الخطوات:**
- المعادلة الحاكمة حسب الموضع:
  - **القمة (أقل شد وأقل سرعة):** $T_{\text{top}} = \frac{mv^2}{r} - mg$
  - **الجانب:** $T_{\text{side}} = \frac{mv^2}{r}$
  - **القاع (أعلى شد وأعلى سرعة):** $T_{\text{bottom}} = \frac{mv^2}{r} + mg$
- **السرعة الحرجة عند القمة ($T=0$):** $v_{\min,\text{top}} = \sqrt{gr}$.
- **أقل سرعة عند القاع لإكمال الدورة الرأسية (بحفظ الطاقة):** $v_{\min,\text{bottom}} = \sqrt{5gr}$.

## 11. نمط الحركة الدائرية الأفقية الثلاثي *(ch12)*
**متى يُستخدم:** بندول مخروطي، كرة داخل مخروط أملس، أو كرة مربوطة بخيط علوي فوق سطح أفقي أملس.
**الخطوات (انتبه أن $\theta$ دائمًا مع الرأسي؛ إن أُعطيت مع الأفقي اطرحها من $90^\circ$):**
1. **البندول المخروطي الحر (قوتان $T, mg$):**
   $$r = l\sin\theta \quad,\quad T = \frac{mg}{\cos\theta} \quad,\quad v = \sqrt{rg\tan\theta} \quad,\quad \tau = 2\pi\sqrt{\frac{l\cos\theta}{g}}$$
2. **كرة داخل مخروط أملس ارتفاعها $h$ عن رأسه (قوتان $N, mg$):**
   $$r = h\tan\theta \quad,\quad N = \frac{mg}{\sin\theta} \quad,\quad v = \sqrt{rg\tan\theta} \quad,\quad \tau = 2\pi\tan\theta\sqrt{\frac{h}{g}}$$
3. **كرة بخيط علوي تلامس سطحًا أفقيًا أملس (ثلاث قوى $T, N, mg$):**
   $$T = m\omega^2 l \quad,\quad N = mg - m\omega^2 l\cos\theta \quad,\quad \tau = \frac{2\pi}{\omega}$$
   *(تنفصل الكرة عن السطح عندما $N \le 0$).*

## 12. نمط نسب كبلر والجاذبية والأقمار الصناعية *(ch13)*
**متى يُستخدم:** مقارنة كوكبين/قمرين يدوران حول نفس الجرم المركزي، أو حساب السرعة المدارية وشدة المجال.
**الخطوات:**
- **انتبه لنصف القطر المداري:** إذا أُعطي ارتفاع $h$ فوق سطح كوكب نصف قطره $R$ فإن $r = R + h$.
- **قانون كبلر الثاني (أقرب وأبعد نقطة لمدار واحد):** $r_1 v_1 = r_2 v_2 \implies \frac{v_1}{v_2} = \frac{r_2}{r_1}$.
- **قانون كبلر الثالث (مداران حول نفس المركز):**
  $$\left(\frac{T_2}{T_1}\right)^2 = \left(\frac{a_2}{a_1}\right)^3 \implies T_2 = T_1\left(\frac{a_2}{a_1}\right)^{1.5}$$
- **نسب السرعة المدارية وشدة المجال حول نفس المركز:**
  $$\frac{v_2}{v_1} = \sqrt{\frac{r_1}{r_2}} \quad,\quad \frac{g_2}{g_1} = \left(\frac{r_1}{r_2}\right)^2$$
