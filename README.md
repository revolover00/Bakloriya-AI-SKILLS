# 🎓 المعلم الذكي لمناهج البكالوريا المصرية (`Bakloriya-AI-SKILLS`)

منصة معرفية مهيكلة تضم مناهج نظام **البكالوريا المصرية (الصف الثاني بكالوريا — ٢ ثانوي — دفعة 2027)** في صورة مهارات وملفات نصية قياسية (`Markdown`)، مما يتيح لأي نموذج ذكاء اصطناعي (ChatGPT، Claude، Gemini، Grok، Perplexity، DeepSeek، Cursor، وغيرها) العمل فورًا كـ **معلم خصوصي خبير بالمنهج المصري** يشرح الدروس، ويحل المسائل والأسئلة الاستنتاجية، ويدرّب الطالب على أنماط الاختبارات بدقة المنهج المقرر دون تأليف.

## ⚡ برومبت ربط الذكاء الاصطناعي بالمستودع الكامل

انسخ هذا البرومبت والصقه في محادثتك مع أي ذكاء اصطناعي ليدخل على المستودع كاملًا بجميع مواده وفصوله ويعمل معك كمعلم خصوصي:

```text
أنت معلمي الخصوصي للصف الثاني بكالوريا (٢ ثانوي - المنهج المصري 2027).
ادخل على مستودع المناهج الكامل من هنا:
https://github.com/revolover00/Bakloriya-AI-SKILLS
واقرأ فهرس جميع المواد وروابط الفصول النصية المباشرة (Raw URLs) من هذا الرابط:
https://raw.githubusercontent.com/revolover00/Bakloriya-AI-SKILLS/main/AGENTS.md

عندما أسألك في أي مادة متاحة بالمستودع (الفيزياء / التاريخ الوطني / اللغة الإنجليزية)، افتح رابط الـ Raw الخاص بالدرس المطلوب من داخل الفهرس، والتزم بشرح وقوانين وقواعد وتعريفات المنهج المقرر بدقة دون تأليف، واختبرني بسؤال تطبيقي في نهاية الشرح.
رحّب بي الآن واسألني: أي مادة وأي درس نبدأ به؟
```

## 🛠️ طرق ربط المستودع بمنصات الذكاء الاصطناعي

### 1. عبر المحادثة المباشرة (ChatGPT / Gemini / Grok / Perplexity / Claude)
- انسخ **برومبت ربط الذكاء الاصطناعي بالمستودع الكامل** من أعلى هذه الصفحة والصقه في المحادثة، أو ادخل إلى صفحة المادة المطلوبة من الجدول أعلاه لنسخ البرومبت الخاص بتلك المادة وحدها.

### 2. عبر المشاريع المخصصة (Claude Projects / ChatGPT Projects / Google NotebookLM / DeepSeek)
- اربط المستودع (`https://github.com/revolover00/Bakloriya-AI-SKILLS`) مباشرةً من خيار **Add from GitHub**، أو حمّل ملفات المادة المطلوبة وارفعها داخل مشروعك مع البرومبت.

### 3. عبر سطر الأوامر وأدوات البرمجة الذكية (Claude Code / Cursor / Windsurf / Copilot)
بفضل وجود ملفَي `AGENTS.md` و`CLAUDE.md` في جذر المستودع، يتحول أي محرر ذكي يفتح هذا المشروع تلقائيًا إلى معلم خصوصي لمنهج البكالوريا المصرية:

```bash
git clone https://github.com/revolover00/Bakloriya-AI-SKILLS.git
cd Bakloriya-AI-SKILLS
```

أو لتثبيت مهارة مادة محددة مباشرةً عبر `npx skills`:

```bash
npx skills add https://github.com/revolover00/Bakloriya-AI-SKILLS --skill second-year-physics
npx skills add https://github.com/revolover00/Bakloriya-AI-SKILLS --skill second-year-history
npx skills add https://github.com/revolover00/Bakloriya-AI-SKILLS --skill second-year-english
```
