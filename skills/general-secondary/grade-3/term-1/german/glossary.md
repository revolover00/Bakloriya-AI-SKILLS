## 👫 Modul 5 : Freunde (الأصدقاء والأنشطة والأماكن — `Lektionen 13–15`)

### 1. الأسماء بأدواتها وجمعها (`Nomen mit Artikel und Plural`)
| المذكر (`der`) | المحايد (`das`) | المؤنث (`die`) |
|---|---|---|
| **der Freund, -e** (الصديق) | **das Hobby, -s** (الهواية) | **die Freundin, -nen** (الصديقة) |
| **der Park, -s** (الحديقة العامة — `in den Park`) | **das Kino, -s** (السينما — `ins Kino`) | **die Stadt, ¨-e** (المدينة — `in die Stadt`) |
| **der Sportplatz, ¨-e** (الملعب — `auf den Sportplatz`) | **das Schwimmbad, ¨-er** (حمام السباحة — `ins Schwimmbad`) | **die Eisdiele, -n** (محل الآيس كريم — `in die Eisdiele`) |
| **der Strand, ¨-e** (الشاطئ — `an den Strand`) | **das Café, -s** (المقهى — `ins Café`) | **die Party, -s** (الحفلة — `auf die Party`) |
| **der Verein, -e** (النادي الرياضي) | **das Konzert, -e** (الحفلة الموسيقية) | **die Hausaufgabe, -n** (الواجب المنزلي) |

### 2. الأفعال المنفصلة والصفات (`Trennbare Verben und Adjektive`)
| الفعل المنفصل (`Trennbares Verb`) | المعنى بالعربية | مثال في المضارع |
|---|---|---|
| **an\|rufen** | يتصل هاتفيًا بـ (+ `Akk.`) | `Ich` **`rufe`** `meinen Freund` **`an`**. |
| **ab\|holen** | يصطحب / يمرّ ليأخذ (+ `Akk.`) | `Wann` **`holst`** `du mich` **`ab`**`?` |
| **mit\|kommen / mit\|machen** | يأتي مع / يشارك | **`Kommst`** `du heute ins Kino` **`mit`**`?` |
| **mit\|bringen / mit\|nehmen** | يحضر معه / يأخذ معه | `Was` **`bringst`** `du zur Party` **`mit`**`?` |
| **ein\|kaufen** | يتسوق | `Am Samstag` **`kaufen`** `wir im Supermarkt` **`ein`**. |
| **fern\|sehen (sieht fern)** | يشاهد التلفاز | `Abends` **`sieht`** `mein Bruder gern` **`fern`**. |
| **an\|fangen (fängt an)** | يبدأ | `Der Film` **`fängt`** `um 20 Uhr` **`an`**. |
| **auf\|stehen / auf\|räumen** | يستيقظ / يرتب الغرفة | `Ich` **`stehe`** `um 6 Uhr` **`auf`** `und` **`räume`** `mein Zimmer` **`auf`**. |

## 🛍️ Modul 6 : Einkaufen (التسوق والهدايا والملابس — `Lektionen 16–18`)

| المذكر (`der` $\rightarrow$ `Akk: den / einen`) | المحايد (`das` $\rightarrow$ `Akk: das / ein`) | المؤنث (`die` $\rightarrow$ `Akk: die / eine`) |
|---|---|---|
| **der Pullover, - (Pulli)** (البلوفر) | **das Geschenk, -e** (الهدية) | **die Jacke, -n** (الجاكيت) |
| **der Rock, ¨-e** (الجيبة/التنورة) | **das T-Shirt, -s / das Hemd, -en** (التيشيرت / القميص) | **die Hose, -n / die Jeans** (البنطلون / الجينز) |
| **der Schal, -s / der Hut, ¨-e** (الكوفية / القبعة) | **das Kleid, -er** (الفستان) | **die Bluse, -n / die Tasche, -n** (البلوزة / الحقيبة) |
| **der Gürtel, - / der Schuh, -e** (الحزام / الحذاء) | **das Buch, ¨-er / das Handy, -s** (الكتاب / الموبايل) | **die Uhr, -en / die Brille, -n** (الساعة / النظارة) |
| **der Preis, -e / der Euro** (السعر / اليورو) | **das Geld** (النقود — مفرد دائمًا) | **die Größe, -n / die Farbe, -n** (المقاس / اللون) |

- **أفعال وتعبيرات التسوق المهمة:** `kosten` (يتكلف)، `kaufen` (يشتري)، `schenken` (يهدي)، `suchen` (يبحث عن)، `brauchen` (يحتاج)، `finden` (يجد/يرى)، `nehmen (nimmt)` (يأخذ)، `tragen (trägt)` (يرتدي)، `anprobieren` (يقيس الملابس)، `günstig / billig` (رخيص/مناسب السعر) $\neq$ `teuer` (غالي).

## 🐾 Modul 7 : Tiere (الحيوانات والمنزل — `Lektionen 19–21`)

| المذكر (`der` $\rightarrow$ `Dat: dem`) | المحايد (`das` $\rightarrow$ `Dat: dem`) | المؤنث (`die` $\rightarrow$ `Dat: der`) |
|---|---|---|
| **der Hund, -e** (الكلب) | **das Tier, -e / das Haustier, -e** (الحيوان / الأليف) | **die Katze, -n** (القطة) |
| **der Vogel, ¨- / der Papagei, -en** (الطائر / الببغاء) | **das Pferd, -e / das Kaninchen, -** (الحصان / الأرنب) | **die Maus, ¨-e / die Schildkröte, -n** (الفأر / السلحفاة) |
| **der Hamster, - / der Fisch, -e** (الهامستر / السمكة) | **das Meerschweinchen, -** (خنزير غينيا الأليف) | **die Schlange, -n / die Spinne, -n** (الثعبان / العنكبوت) |
| **der Käfig, -e / der Garten, ¨-** (القفص / الحديقة) | **das Aquarium, Aquarien** (حوض السمك) | **die Wohnung, -en / die Küche, -n** (الشقة / المطبخ) |
| **der Tisch, -e / der Stuhl, ¨-e** (المنضدة / الكرسي) | **das Bett, -en / das Sofa, -s** (السرير / الكنبة) | **die Tür, -en / die Wand, ¨-e** (الباب / الحائط) |

- **أفعال تأخذ `Dativ` دائمًا (`Verben mit Dativ`):**
  - **`helfen` (hilft)** (يساعد): `Ich helfe` **`meinem Vater / dir`**.
  - **`gehören`** (يخصّ/ملكيّة): `Wem gehört der Hund? — Er gehört` **`mir / dem Lehrer`**.
  - **`gefallen` (gefällt)** (يعجب): `Die Katze gefällt` **`uns`** `sehr.`
  - **`schmecken` / `passen` / `danken` / `gratulieren`** (يعجب مذاقه / يناسب مقاسه / يشكر / يهنئ).

## ✈️ Modul 8 : Ferien und Reisen (الإجازات والسفر والمواصلات — `Lektionen 22–24`)

|---|---|---|
| **der Urlaub / die Ferien (Pl.)** (الإجازة / العطلة المدرسية — جمع دائمًا!) | **das Flugzeug, -e** (الطائرة — `mit dem Flugzeug`) | **die Reise, -n** (الرحلة) |
| **der Zug, ¨-e** (القطار — `mit dem Zug`) | **das Auto, -s** (السيارة — `mit dem Auto`) | **die U-Bahn, -en** (المترو — `mit der U-Bahn`) |
| **der Bus, -se** (الأتوبيس — `mit dem Bus`) | **das Fahrrad, ¨-er (Rad)** (الدراجة — `mit dem Rad`) | **die Straßenbahn, -en** (الترام — `mit der Straßenbahn`) |
| **der Bahnhof, ¨-e** (محطة القطار — `zum Bahnhof`) | **das Schiff, -e / das Boot, -e** (السفينة / القارب) | **die Jugendherberge, -n** (بيت الشباب) |
| **der Koffer, - / der Rucksack, ¨-e** (حقيبة السفر / الظهر) | **das Hotel, -s / das Zelt, -e** (الفندق / الخيمة) | **die Sehenswürdigkeit, -en** (المَعلم السياحي) |
