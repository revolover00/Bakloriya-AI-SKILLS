# 🧩 أنماط القواعد الذهبية ومصائد الامتحانات (Patterns & Prüfungsfallen — Deutsch A1.2)
**اللغة الألمانية (لغة ثانية) — الصف الثاني بكالوريا**

---

## ⚠️ النمط الأول: جدول الحالات الإعرابية الثلاث (`Nominativ · Akkusativ · Dativ`)

| النوع (`Genus`) | **Nominativ** (فاعل — `Wer? / Was?`) | **Akkusativ** (مفعول به / حركة — `Wen? / Was? / Wohin?`) | **Dativ** (مفعول لأجله / سكون — `Wem? / Wo? / Womît?`) |
|---|---|---|---|
| **المذكر (`Maskulin`)** | **der** / **ein** / **kein** / **mein** | 🔥 **den** / **einen** / **keinen** / **meinen** | 🔥 **dem** / **einem** / **keinem** / **meinem** |
| **المحايد (`Neutral`)** | **das** / **ein** / **kein** / **mein** | **das** / **ein** / **kein** / **mein** | 🔥 **dem** / **einem** / **keinem** / **meinem** |
| **المؤنث (`Feminin`)** | **die** / **eine** / **keine** / **meine** | **die** / **eine** / **keine** / **meine** | 🔥 **der** / **einer** / **keiner** / **meiner** |
| **الجمع (`Plural`)** | **die** / **—** / **keine** / **meine** | **die** / **—** / **keine** / **meine** | 🔥 **den (+ -n)** / **— (+ -n)** / **keinen (+ -n)** / **meinen (+ -n)** |

- **قاعدة أداة الاستفهام `welch-` واسم الإشارة `dies-`:** يأخذان نفس نهايات أداة التعريف بالضبط (`der -> welcher/dieser`, `den -> welchen/diesen`, `das -> welches/dieses`, `die -> welche/diese`, `dem -> welchem/diesem`, `der -> welcher/dieser`).

## ⚠️ النمط الثاني: جدول الضمائر الشخصية في الحالات الثلاث (`Personalpronomen`)

| **Nominativ** (`Wer?`) | **Akkusativ** (`Wen?` — بعد `sehen, besuchen, anrufen, fragen, lieben, brauchen, für, ohne`) | **Dativ** (`Wem?` — بعد `helfen, gehören, gefallen, passen, schmecken, danken, geben, mit, zu, bei, von`) | **Possessivartikel** (أداة الملكية) |
|---|---|---|---|
| **ich** (أنا) | **mich** | **mir** | **mein / meine** |
| **du** (أنتَ/أنتِ) | **dich** | **dir** | **dein / deine** |
| **er** (هو — مذكر) | **ihn** | **ihm** | **sein / seine** |
| **es** (هو/هي — محايد) | **es** | **ihm** | **sein / seine** |
| **sie** (هي — مؤنث) | **sie** | **ihr** | **ihr / ihre** |
| **wir** (نحن) | **uns** | **uns** | **unser / unsere** |
| **ihr** (أنتم) | **euch** | **euch** | **euer / eure** *(حذف `e` عند الإضافة!)* |
| **sie** (هم — جمع) | **sie** | **ihnen** | **ihr / ihre** |
| **Sie** (حضرتك/حضراتكم) | **Sie** | **Ihnen** | **Ihr / Ihre** *(بحرف كبير دائمًا!)* |

## ⚠️ النمط الثالث: المقارنة الذهبية بين `Wohin?` (حركة) و`Wo?` (سكون)

| السؤال والدلالة | الأفعال المفتاحية | حروف الجر والحالة الإعرابية | الاختصارات والأمثلة القياسية |
|---|---|---|---|
| **1. `Wohin?` (إلى أين — حركة واتجاه)** | `gehen, fahren, fliegen, kommen, reisen, laufen` | • **`in / an / auf` + `Akkusativ`**<br>• **`zu` + `Dativ`** (للأشخاص والأماكن داخل المدينة)<br>• **`nach`** (للدول والمدن بلا أداة + `nach Hause`) | • `in + das` = **`ins`** (`ins Kino / ins Café / ins Schwimmbad`)<br>• `in + den` = `in den Park` · `in + die` = `in die Stadt / Schule`<br>• `an + das` = **`ans`** `Meer` · `an + den` = `an den Strand`<br>• `zu + dem` = **`zum`** `Bahnhof / Arzt` · `zu + der` = **`zur`** `Schule / Post` |
| **2. `Wo?` (أين — ثبات ومكان)** | `sein, wohnen, liegen, stehen, sitzen, bleiben, arbeiten, spielen` | • **`in / an / auf / über / unter / vor / hinter / neben / zwischen` + `Dativ`**<br>• **`bei` + `Dativ`** | • `in + dem` = **`im`** (`im Kino / im Park / im Garten / im Bett`)<br>• `in + der` = `in der Schule / in der Stadt / in der Küche`<br>• `an + dem` = **`am`** (`am Strand / am Meer / am Bahnhof`)<br>• **`zu Hause`** (في المنزل) $\neq$ **`nach Hause`** (إلى المنزل)! |

## ⚠️ النمط الرابع: زمن المضارع التام (`Das Perfekt`) — متى نستخدم `haben` ومتى نستخدم `sein`؟

1. **التركيب (`Satzklammer`):**
   $$\text{Position 2: } \mathbf{haben / sein}\ (\text{مصرف في المضارع}) \quad \cdots \quad \text{Satzende (آخر الجملة): } \mathbf{Partizip\ II}$$
2. **الأفعال التي تأخذ المساعد `sein` (حفظ إلزامي — `Lektion 24`):**
   - **أفعال الحركة الانتقالية وتغير المكان:**
     - `gehen` $\rightarrow$ **`ist gegangen`** · `fahren` $\rightarrow$ **`ist gefahren`** · `fliegen` $\rightarrow$ **`ist geflogen`** · `kommen` $\rightarrow$ **`ist gekommen`** · `reisen` $\rightarrow$ **`ist gereist`** · `schwimmen` $\rightarrow$ **`ist geschwommen`** · `laufen` $\rightarrow$ **`ist gelaufen`** · `wandern` $\rightarrow$ **`ist gewandert`** · `abfahren` $\rightarrow$ **`ist abgefahren`**.
   - **أفعال تغير الحالة والبقاء والكينونة:**
     - `aufstehen` $\rightarrow$ **`ist aufgestanden`** · `einschlafen` $\rightarrow$ **`ist eingeschlafen`** · `bleiben` $\rightarrow$ **`ist geblieben`** · `sein` $\rightarrow$ **`ist gewesen`** · `passieren` $\rightarrow$ **`ist passiert`**.
3. **جميع الأفعال الأخرى تأخذ المساعد `haben`:**
   - **أفعال قياسية (`ge- + Stamm + -t`):** `machen` $\rightarrow$ `hat gemacht`, `kaufen` $\rightarrow$ `hat gekauft`, `spielen` $\rightarrow$ `hat gespielt`, `lernen` $\rightarrow$ `hat gelernt`, `hören` $\rightarrow$ `hat gehört`, `wohnen` $\rightarrow$ `hat gewohnt`, `einkaufen` $\rightarrow$ `hat eingekauft`.
   - **أفعال تنتهي بـ `-ieren` (بدون `ge-`!):** `fotografieren` $\rightarrow$ **`hat fotografiert`**, `studieren` $\rightarrow$ **`hat studiert`**, `telefonieren` $\rightarrow$ **`hat telefoniert`**.
   - **أفعال غير قياسية شائعة (`ge- + ... + -en`):** `sehen` $\rightarrow$ `hat gesehen`, `lesen` $\rightarrow$ `hat gelesen`, `essen` $\rightarrow$ `hat gegessen`, `trinken` $\rightarrow$ `hat getrunken`, `schreiben` $\rightarrow$ `hat geschrieben`, `schlafen` $\rightarrow$ `hat geschlafen`, `treffen` $\rightarrow$ `hat getroffen`, `nehmen` $\rightarrow$ `hat genommen`, `helfen` $\rightarrow$ `hat geholfen`, `anrufen` $\rightarrow$ `hat angerufen`, `fernsehen` $\rightarrow$ `hat ferngesehen`, `mitbringen` $\rightarrow$ `hat mitgebracht`.
