# قاموس المصطلحات: اللغة الصينية (الكتاب ج) — الصف الثاني بكالوريا — الفصل الدراسي الثاني

| المصطلح | التعريف والشرح المنهجي |
|---|---|
| **点 / 分 / 半 / 刻** | مفردات الوقت: ساعة (diǎn)، دقيقة (fēn)، نصف (bàn)، ربع (kè). |
| **件 (jiàn)** | كلمة قياس للملابس العلوية (مثل القميص والمعطف). |
| **双 (shuāng)** | كلمة قياس للأشياء الزوجية (الأحذية والجوارب). |
| **条 (tiáo)** | كلمة قياس للأسماك والبنطلون والأشياء الطويلة المرنة. |
