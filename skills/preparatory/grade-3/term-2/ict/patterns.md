# أنماط الأسئلة المتكررة ومفاتيح الحل: الكمبيوتر وتكنولوجيا المعلومات والاتصالات — الصف الثالث الإعدادي (الشهادة الإعدادية) — الفصل الدراسي الثاني

- **المحور الأساسي:** أنظمة التشغيل، الشبكات، الأمن السيبراني، تصميم المواقع، والبرمجة والذكاء الاصطناعي (الصف الثالث الإعدادي (الشهادة الإعدادية) — الفصل الدراسي الثاني).

## منهجية الحل التدريجي
1. قراءة السؤال وتحديد المفهوم أو القانون المطلوب.
2. تطبيق القاعدة خطوة بخطوة مع كتابة الوحدات أو التشكيل أو خطوات البرهان.
3. تعليل سبب اختيار الإجابة الصحيحة وسبب استبعاد البدائل الخاطئة.
